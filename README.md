## 🚀 Getting Started

Each subdirectory is a self-contained Maven project. To work with a specific project:

```bash
# Navigate to the project
cd BASICS/
# or
cd Framework-Practice-2/
# or
cd Java_practice/

# Build with Maven
mvn clean install

# Run tests
mvn test
```

## 📝 Notes

- Each project maintains its own `pom.xml` configuration
- Projects can be built and tested independently
- All projects are Java-based using Maven for dependency management
