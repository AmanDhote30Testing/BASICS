# Selenium Framework — From Scratch

Building a Selenium WebDriver framework step by step in Java.
This is my practice repo for understanding how frameworks are structured
before working with production-grade ones.

## Stack
- Java 23
- Selenium WebDriver 4.27
- TestNG 7.10
- Maven

## Run tests
```bash
mvn clean test
```

## What's in here
- Basic WebDriver setup
- Page Object Model structure
- TestNG test classes
- Utility methods (screenshots, waits)

## Notes
Still a work in progress. Each commit adds a new concept.
